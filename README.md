
# 📚 Navana Learning Skills

Welcome to Navana Learning Skills!

A technical learning platform built using Java, Spring Boot, Maven, HTML, CSS, JavaScript and MySQL/H2.

## 🚀 Project Overview

Navana Learning Skills provides technical learning resources in three main categories:

1. DevOps
2. IT Support
3. Microsoft Intune

## ▶️ How to Run the Project

### Step 1: Clone the Repository

```bash
git clone <your-github-repository-url>
```

### Step 2: Navigate to Project

```bash
cd navana-learning-skills
```

### Step 3: Check Java Version

```bash
java -version
```

### Step 4: Check Maven Version

```bash
mvn -version
```

### Step 5: Build the Project

```bash
mvn clean install
```

### Step 6: Run Spring Boot

```bash
mvn spring-boot:run
```

### Step 7: Open Website

```text
http://localhost:8080/
```
